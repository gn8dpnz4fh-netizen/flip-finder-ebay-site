FLIP FINDER EBAY SANDBOX STARTER SITE

This package is a starter for eBay Sandbox OAuth configuration. It does NOT connect to eBay by itself and contains no eBay keys.

BEFORE PUBLISHING:
1. Open privacy.html and replace REPLACE-WITH-YOUR-CONTACT-EMAIL with a contact email you control.
2. Review the privacy policy so it accurately reflects what Flip Finder actually does. Do not use this starter policy unchanged for a public/production release.

FREE HOSTING WITH GITHUB PAGES:
1. Sign in at https://github.com/ or create a free account.
2. Create a new PUBLIC repository named: flip-finder-ebay-site
3. Upload index.html, privacy.html, accepted.html, and declined.html to the repository root.
4. In the repository, open Settings > Pages.
5. Under Build and deployment, choose Deploy from a branch; select main and / (root), then Save.
6. Wait for GitHub Pages to provide the site URL. It will look like:
   https://YOUR-GITHUB-USERNAME.github.io/flip-finder-ebay-site/

Use these URLs in the eBay Sandbox RuName form (the domain/path must match your real published Pages URL):
Display title: Flip Finder (Sandbox)
Privacy Policy URL: https://YOUR-GITHUB-USERNAME.github.io/flip-finder-ebay-site/privacy.html
Auth Accepted URL: https://YOUR-GITHUB-USERNAME.github.io/flip-finder-ebay-site/accepted.html
Auth Declined URL: https://YOUR-GITHUB-USERNAME.github.io/flip-finder-ebay-site/declined.html

Important: Replace YOUR-GITHUB-USERNAME with your actual username. These are templates until GitHub Pages is published. Never put App ID, Cert ID, tokens, or passwords in these site files or repository.
