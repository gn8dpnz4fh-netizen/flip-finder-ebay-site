Information and local storage

Flip Finder is a desktop application intended to help users research resale items and manage listings. Item details, images, and other information that a user enters may be saved in files on the user's own computer. Anyone with access to those files or the computer may be able to view that information.

eBay connection

If a user chooses to connect an eBay account, Flip Finder may use eBay's authorization process and APIs to provide the eBay features the user requests. The user should review the permissions shown by eBay before approving access. Listing details and photos are sent to eBay only when the user uses an eBay feature that submits that information. eBay's own privacy policy applies to information eBay processes on its services.

Sharing and security

Do not share API secrets, authorization tokens, or configuration files containing credentials. A local application cannot guarantee security if the computer or local files are compromised. Flip Finder does not ask users to send eBay passwords to the app; authentication should occur on eBay's own site.
